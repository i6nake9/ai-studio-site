# Nerutyna — сайт студії ШІ-автоматизації

Сайт українською: головна з калькулятором економії, сторінки послуг і галузей, ціни, блог, форма заявки.
Статичний (Next.js `output: 'export'`): сторінки збираються заздалегідь, бази даних у сайту немає.

Основна адреса: <https://nerutyna.com.ua>. Копія на GitHub Pages: <https://i6nake9.github.io/ai-studio-site/>
(закрита від пошукових систем, форма там лише показує текст заявки).

## Запуск

Потрібен Node.js 22 або новіший.

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # тести логіки калькулятора, заявки й текстів
npm run build   # готовий сайт у папці out/
```

### Сторінки послуг і пошук

Кожен напрямок із `solutions.items` у `src/content/uk.ts` має власну сторінку `/poslugy/<slug>/`:
заголовок і опис для пошуку (`page.metaTitle` до 60 знаків, `page.metaDescription` 110–160 знаків),
вступ, «кому підходить» і питання. Нова послуга в списку сама отримує сторінку, посилання в підвалі
й рядок у карті сайту. Розмітку для пошукових систем (організація, послуга, питання) сторінки
будують із цих самих текстів, окремо її писати не треба.

### Сторінки задач і галузей

- `src/content/tasks.ts` — конкретні задачі (ТТН з Prom.ua з друком, друк етикеток, GPS-трекери,
  IP-телефонія тощо). Кожна має поле `parent` (адреса одного з чотирьох напрямків) і сторінку
  `/poslugy/<slug>/`: що болить зараз, кроки роботи, що входить, інтеграції, кому підходить, питання.
- `src/content/industries.ts` — сторінки під тип бізнесу, `/galuzi/<slug>/`. У `services` перелік
  задач і напрямків із поясненням `why` для цього бізнесу.
- `src/content/catalog.ts` — заголовки цих сторінок і двох покажчиків: `/poslugy/` та `/galuzi/`.

- `src/content/tasks-search.ts` — ще задачі, написані під пошукові запити (розробка Telegram-бота,
  інтеграція з 1С і BAS, автоматичне створення ТТН, парсинг сайтів тощо). Той самий формат; `tasks.ts`
  додає цей список до свого.

Новий запис у `tasks.ts`, `tasks-search.ts` чи `industries.ts` сам отримує сторінку, картку на головній, у покажчику
й рядок у карті сайту. Тести (`src/content/catalog.test.ts`) перевіряють довжину заголовка й опису,
унікальність адрес, що кожна задача має галузь, яка на неї посилається, і що в текстах немає
обіцянок, відсотків та згадок про клієнтів.

### Засновник

У `site.config.ts` поле `founder`: `name` — ім'я, `photo` — файл у `public/` (наприклад `founder.jpg`).
Поки ім'я порожнє, блок «Хто з вами працює» показує лише текст без імені й фото.

### Бот у Telegram

У `site.config.ts` поле `telegram` — ім'я бота студії без `@`. Усі кнопки Telegram на сайті
відкривають цього бота: він ставить три запитання, питає згоду на розсилку й передає розмову
власнику. Поки поле порожнє, кнопок Telegram на сайті немає. Якщо порожні і `telegram`,
і `email`, і `leadEndpoint`, замість форми сайт показує напис «Прийом заявок ще не ввімкнено».

### Як приходять заявки

Форма питає ім'я, сайт або нішу й e-mail (обов'язкові), нік у Telegram (за бажанням) і має
окреме поле згоди на розсилку, яке відвідувач позначає сам. Телефон не питаємо: спілкування
письмове.

Форма надсилає `POST` з JSON на адресу з `leadEndpoint` (береться зі змінної
`NEXT_PUBLIC_LEAD_ENDPOINT` під час збирання). Приймач зберігає заявку разом із текстом і часом
згоди, повідомляє власника в Telegram і повертає посилання, яким відвідувач продовжує розмову
в боті. Якщо адреси немає або приймач не відповів, відвідувач бачить текст заявки, кнопку
«Скопіювати» й посилання на бота: «надіслано» сайт пише лише тоді, коли заявка справді дійшла.

Що сайт робить з даними, описано на сторінці «Конфіденційність» (`privacy` у `src/content/uk.ts`).
Якщо зміниться збір даних (нове поле, лічильник, рекламний піксель), спершу оновіть цей текст.

### Демо-відео

Додайте файли в `public/` і пропишіть їх у `scenarios.videos` у `src/content/uk.ts`.
Поки список порожній, смуги з відео на сторінці немає.

## Правила текстів

Тест `src/content/uk.test.ts` не дає додати на сайт обіцянки, яких ми не можемо підтвердити:
цифри результатів клієнтів, «гарантуємо», вигадані відсотки. Сценарії названі прикладами, а не історіями клієнтів.
Той самий тест стежить за довжиною заголовків і описів для пошуку.

### Блог і сторінка цін

- `src/content/articles.ts` — статті блогу, `/blog/<slug>/`. Кожна відповідає на одне питання з пошуку:
  `summary` (сама відповідь, двома-чотирма реченнями, показується першою), розділи з текстом і списками,
  питання, `related` (адреси послуг, на які стаття веде). Нова стаття сама з'являється в блозі,
  на головній, на сторінках пов'язаних послуг, у карті сайту й у `llms.txt`.
- `src/content/pricing.ts` — сторінка цін `/ciny/`: що входить у кожен формат, від чого залежить ціна,
  що оплачується окремо. Самі цифри беруться з `site.config.ts`.
- `/llms.txt` — коротка карта сайту для ШІ-асистентів; збирається з тих самих файлів (`src/lib/llms.ts`).

Правила для текстів ті самі (`src/content/articles.test.ts`): відповідь спочатку, без вигаданих цифр,
без обіцянок і без згадок про клієнтів.

### Мітки реклами

Якщо людина прийшла за посиланням з мітками `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`,
`utm_term`, вони запам'ятовуються на час візиту й потрапляють у заявку поруч з адресою сторінки
(`src/lib/attribution.ts`). Ідентифікатори кліків (`fbclid`, `gclid`) не зберігаються.

## Публікація

Кожен push у `main` запускає `.github/workflows/pages.yml`: тести, збірка, викладка на GitHub Pages.

## Свій домен

Сайт працює на домені `nerutyna.com.ua` з власного сервера; адреса за замовчуванням записана в
`site.config.ts` (`siteUrl`), а збірка керується трьома змінними:

```
NEXT_PUBLIC_BASE_PATH=""                      # сайт у корені домену
NEXT_PUBLIC_SITE_URL=https://nerutyna.com.ua
NEXT_PUBLIC_NOINDEX=false                     # дозволити пошуковим системам
```

Поки `NEXT_PUBLIC_NOINDEX` не дорівнює `false`, на кожній сторінці стоїть позначка «не індексувати».
Після відкриття додайте сайт у Google Search Console та Bing Webmaster Tools і надішліть туди
`https://nerutyna.com.ua/sitemap.xml`.

Якщо змінюється назва, оновіть `brand` у `site.config.ts` і перемалюйте `public/og.png`.
