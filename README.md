# Nerutyna — сайт студії ШІ-автоматизації

Односторінковий сайт українською: послуги, калькулятор економії, типові сценарії, форма заявки.
Статичний (Next.js `output: 'export'`), без сервера й без бази даних.

Тимчасова адреса: <https://i6nake9.github.io/ai-studio-site/> (закрита від пошукових систем, доки немає свого домену).

## Запуск

Потрібен Node.js 22 або новіший.

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # тести логіки калькулятора, заявки й текстів
npm run build   # готовий сайт у папці out/
```

### Сторінки послуг і пошук

Кожен напрямок із `solutions.items` у `src/content/uk.ts` має власну сторінку `/poslugy/<slug>/`:
заголовок і опис для пошуку (`page.metaTitle` до 60 знаків, `page.metaDescription` 110–160 знаків),
вступ, «кому підходить» і питання. Нова послуга в списку сама отримує сторінку, посилання в підвалі
й рядок у карті сайту. Розмітку для пошукових систем (організація, послуга, питання) сторінки
будують із цих самих текстів, окремо її писати не треба.

### Засновник

У `site.config.ts` поле `founder`: `name` — ім'я, `photo` — файл у `public/` (наприклад `founder.jpg`).
Поки ім'я порожнє, блок «Хто з вами працює» показує лише текст без імені й фото.

### Картинка для посилань

Змініть `tools/og.html` і перемалюйте:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --hide-scrollbars \
  --window-size=1200,630 --virtual-time-budget=8000 \
  --screenshot="$PWD/public/og.png" "file://$PWD/tools/og.html"
```

### Нік у Telegram

У `site.config.ts` поле `telegram` — нік без `@`. Поки воно порожнє, кнопок Telegram на сайті немає.
Якщо порожні і `telegram`, і `email`, і `leadEndpoint`, замість форми сайт показує напис
«Прийом заявок ще не ввімкнено». **Без ніка заявки до вас не дійдуть.**

### Як приходять заявки

Сервера немає, тому форма не надсилає нічого сама. Після заповнення відвідувач бачить текст заявки
й кнопку, яка відкриває Telegram з цим текстом; йому лишається натиснути «Надіслати».

Якщо згодом з'явиться приймач заявок (наприклад, бот), впишіть його адресу в `leadEndpoint`:
форма надсилатиме туди `POST` з JSON, а шлях через Telegram лишиться запасним.
Тоді оновіть текст сторінки «Конфіденційність» у `src/content/uk.ts`.

### Демо-відео

Додайте файли в `public/` і пропишіть їх у `scenarios.videos` у `src/content/uk.ts`.
Поки список порожній, смуги з відео на сторінці немає.

## Правила текстів

Тест `src/content/uk.test.ts` не дає додати на сайт обіцянки, яких ми не можемо підтвердити:
цифри результатів клієнтів, «гарантуємо», вигадані відсотки. Сценарії названі прикладами, а не історіями клієнтів.
Той самий тест стежить за довжиною заголовків і описів для пошуку.

## Публікація

Кожен push у `main` запускає `.github/workflows/pages.yml`: тести, збірка, викладка на GitHub Pages.

## Свій домен

1. У `.github/workflows/pages.yml` змініть три змінні:

   ```yaml
   NEXT_PUBLIC_BASE_PATH: ""
   NEXT_PUBLIC_SITE_URL: https://ваш-домен
   NEXT_PUBLIC_NOINDEX: "false"
   ```

   Поки `NEXT_PUBLIC_NOINDEX` увімкнено, пошукові системи сайт не показують. Після перемикання
   додайте сайт у Google Search Console і надішліть туди `https://ваш-домен/sitemap.xml`.

2. Додайте файл `public/CNAME` з одним рядком — вашим доменом.
3. У DNS домену: запис `CNAME` на `i6nake9.github.io` (для `www`) або чотири записи `A` GitHub Pages для кореня домену.
4. У налаштуваннях репозиторію: Settings → Pages → Custom domain, увімкніть Enforce HTTPS.
5. Якщо змінюється назва, оновіть `brand` у `site.config.ts` і перемалюйте `public/og.png`.
